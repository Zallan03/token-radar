Token Launch Radar — ranks every pre-token protocol in the DefiLlama snapshot by implied token value and gives each one a concrete farm plan. Model radar-2 derives its value from the snapshot's own figures: each category's multiple is the median market-cap-to-TVL ratio of the snapshot's own live-token protocols in that category, combined with 7-day TVL growth, time listed with no token, and chain breadth. The board covers all 40 watchlist protocols plus every other rankable pre-token protocol (198 rows), keeps live-token protocols apart at the market's own value, and ships a sortable, filterable dashboard with a detail view and farm plan per protocol.

## Run it

```sh
node main.ts --input snapshot.json --output out
```
